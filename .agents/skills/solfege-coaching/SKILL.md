# Solfege Coaching

## Goal

Create short, progressive solfege and ear-training exercises that are easy to practice, self-check, and revise.

## Recommended Inputs

- learner level
- fixed-do or movable-do preference
- note names or scale-degree preference
- rhythm level
- pitch range
- target concept such as intervals, tonic function, dictation, or sight-singing

## Workflow

1. Identify the single main learning goal.
2. Separate `Confirmed` information from `Assumption`.
3. If the drill should map to an instrument, apply the matching reusable instrument skill.
4. Build one short exercise block that trains exactly that goal.
5. Include an answer key or self-check method.
6. Note the most likely mistake.
7. Suggest the next difficulty step.

## Output Contract

- `Lesson Goal`
- `Confirmed`
- `Assumption`
- `Exercise`
- `Answer Key`
- `Common Mistake`
- `Next Drill`

## Guardrails

- do not mix too many skills into one beginner exercise
- do not omit answer keys when the task is self-study
- do not claim live performance assessment without evidence
- keep the difficulty progression incremental
