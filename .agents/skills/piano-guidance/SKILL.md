# Piano Guidance

## Goal

Adapt musical advice for piano so chord voicings, melodic spacing, and harmonic demonstrations fit keyboard-based playing and visualization.

## Use With

- `composer`
- `music-theory-teacher`
- `producer`
- `solfege-teacher`
- `music-director`

## Workflow

1. Identify whether the task is about voicing, accompaniment, melody, or theory demonstration.
2. Consider left-hand and right-hand distribution, register density, and sustain behavior.
3. Prefer examples that show clear note spacing and avoid muddy low-register stacks.
4. If teaching, connect the explanation to visible keyboard interval shapes.
5. If context is thin, say which hand-span or skill assumptions you made.

## Guardrails

- do not assume advanced hand reach unless stated
- do not suggest low-register clusters without warning about mud
- keep examples readable on the keyboard, not only theoretically correct
