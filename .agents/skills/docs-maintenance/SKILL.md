# Docs Maintenance

## Goal

Keep repository truth explicit.

## Workflow

1. Identify what decision changed.
2. Update `MANIFEST.md` if direction or scope changed.
3. Update affected files in `docs/`.
4. Update `STRUCTURE.md` if boundaries changed.
5. Keep `Confirmed`, `Assumption`, `Risk`, `Deferred`, and `Open Question` explicit.
