# Лаунчер Claude Code в «терминальном» стиле

## Confirmed

- Скрипт `scripts/claude_terminal.py` печатает баннер (Unicode-рамка, ANSI-цвета при TTY) в **stderr**.
- Если доступен `POLYPHONIA_CLAUDE_API_KEY` или `ANTHROPIC_API_KEY`, скрипт открывает **стабильный простой REPL** поверх Anthropic Messages API вместо нативного TUI Claude Code.
- Если Claude key не задан, скрипт **запрашивает одноразовый ключ прямо в консоли** и остаётся в стабильном REPL.
- Только при `--native` (или явном выборе `/native` в стартовом prompt) скрипт делает **`exec`** в `claude` из PATH.
- Режим только баннера: `python scripts/claude_terminal.py --banner-only` (код выхода `0`, без запуска `claude`).
- Цвета отключаются при непустой переменной окружения **`NO_COLOR`**.
- На Windows при цветном выводе включается режим **VT100** в консоли, если доступно.

## Assumption

- Для стабильного REPL у пользователя есть рабочий Claude API key из Anthropic Console, уже сохранённый в Polyphonia или доступный для одноразового ввода в консоли.
- Установленный CLI **Claude Code** по-прежнему может использоваться как запасной путь, но больше не нужен для базового рабочего чата.

## Risk

- Простой REPL не заменяет весь tool-enabled опыт нативного Claude Code CLI: это сознательный trade-off в пользу стабильного ввода на Windows.
- В узких терминалах без поддержки Unicode рамки могут отображаться «ломано» — тогда используйте широкий шрифт UTF-8 или `NO_COLOR=1`.
