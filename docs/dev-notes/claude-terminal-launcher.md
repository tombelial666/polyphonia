# Лаунчер Claude Code в «терминальном» стиле

## Confirmed

- Скрипт `scripts/claude_terminal.py` печатает баннер (Unicode-рамка, ANSI-цвета при TTY) в **stderr**, затем делает **`exec`** в `claude` из PATH с теми же аргументами, что и у лаунчера.
- Режим только баннера: `python scripts/claude_terminal.py --banner-only` (код выхода `0`, без запуска `claude`).
- Цвета отключаются при непустой переменной окружения **`NO_COLOR`** (соглашение de facto).
- На Windows при цветном выводе включается режим **VT100** в консоли, если доступно.

## Assumption

- Установлен официальный CLI **Claude Code** и команда `claude` доступна в PATH.

## Risk

- В узких терминалах без поддержки Unicode рамки могут отображаться «ломано» — тогда используйте широкий шрифт UTF-8 или `NO_COLOR=1` и при необходимости правьте терминал.
