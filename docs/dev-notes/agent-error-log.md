# Журнал ошибок агента (ежедневный ретро‑лог)

Цель: фиксировать **каждую ошибку**, которая привела к неправильному коду/поведению/процессу, и добавлять короткое **“как не повторять”**.

Формат записи (1 блок на ошибку):

- **Дата**:
- **Контекст**: где/в каком сценарии проявилось
- **Симптом**: что увидели (лог/скрин/ошибка)
- **Причина**: почему так вышло (честно)
- **Фикс**: что изменили (файлы/ключевые места)
- **Профилактика**: тест/проверка/правило, чтобы не повторить

## 2026-04-23

- **Дата**: 2026-04-23  
  **Контекст**: Windows PowerShell в Cursor терминале.  
  **Симптом**: команды с `&&` падали парсером PowerShell при запуске через оболочку (`git diff && git diff --staged`, `git fetch && ...`).  
  **Причина**: предположил bash-совместимое чейнирование команд, но в PowerShell это другой оператор.  
  **Фикс**: перешёл на отдельные команды (несколько вызовов) вместо `&&`.  
  **Профилактика**: правило “в PowerShell не использовать `&&`; либо использовать `;`, либо разносить команды”.
