# Admin CLI — запуск команд из корня репозитория (операторский токен)

## Confirmed

- Точка входа: [scripts/repo_admin_cli.py](../../scripts/repo_admin_cli.py).
- Выполнение **только** если одновременно:
  - непустая переменная окружения **`PETS_OPERATOR_TOKEN`** (общий смысл «секрет оператора»; не коммитить);
  - текущий `cwd` **строго равен** корню репозитория (`MANIFEST.md` + `build_index.py`).
- Команда — **список аргументов**, `shell=False`.

## Assumption

- Тот же класс секрета, что и для других привилегированных операций в будущем, можно унифицировать под `PETS_OPERATOR_TOKEN` (без хранения в git).

## Risk

- Токен в переменных окружения виден дочерним процессам и инструментам на машине — использовать только на доверенной рабочей станции.

## Примеры

PowerShell (из корня PETS):

```powershell
$env:PETS_OPERATOR_TOKEN = "your-long-secret"
python scripts/repo_admin_cli.py -- python -c "print(42)"
```

## Отложено

- Allowlist команд, лог-файл, отдельная проверка хеша токена — по задаче.
