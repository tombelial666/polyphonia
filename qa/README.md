# QA layer (`qa/`)

## Confirmed

- В этом каталоге живёт **всё, что относится к проверке качества PETS**, без смешивания с рантайм-слоем (`phrygian_app.py`, `index.html`, `assets/`).
- **Версионируемое** (коммитим): только `qa/packages/` и этот `README.md`.
- **Эфемерное** (не коммитим): всё под `qa/results/` — JUnit, локальные логи, скриншоты из ручных прогонов.

## Layout

| Путь | Назначение |
|------|------------|
| `qa/packages/<feature>/` | Набор документов по фиче: контракт выходов, кейсы, матрица трассировки, runbook, summary-шаблон. |
| `qa/results/` | Локальный «свалочный» слой для машинных отчётов; каталог в `.gitignore`. |

## Assumption

- Новые QA-пакеты появляются как `qa/packages/<краткое-имя-фичи>/`, без произвольных хэшей в корне `qa/`.

## Risk

- Если класть отчёты рядом с доками внутри `qa/packages/`, со временем репозиторий засоряется; поэтому отчёты строго в `qa/results/`.

## Relation to `tests/`

- Исполняемые тесты остаются в `tests/` (см. `tests/e2e/` для браузерных сценариев).
- Документация по запуску для разработчиков: `docs/testing/`.
