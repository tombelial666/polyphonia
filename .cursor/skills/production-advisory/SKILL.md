# Production Advisory

## Goal

Turn a musical or sonic brief into prioritized production moves, tradeoffs, and next-step recommendations that the user can actually test.

## Recommended Inputs

- genre or stylistic target
- current problem statement
- arrangement summary
- available instrumentation
- recording context
- DAW, plugin, or hardware constraints when relevant

## Workflow

1. Classify the request as arrangement, sound design, recording, mixing, or a combination.
2. Separate `Confirmed` information from `Assumption`.
3. If the instrument is central to the issue, apply the matching reusable instrument skill.
4. State the top 2-4 passes in priority order.
5. Offer a small number of options with clear tradeoffs.
6. Flag where missing audio limits certainty.
7. End with one concrete next studio move.

## Output Contract

- `Goal`
- `Confirmed`
- `Assumption`
- `Priority Passes`
- `Options`
- `Risk`
- `Next Studio Move`

## Guardrails

- no pretending to hear frequency, transient, or stereo issues without evidence
- no invented plugin presets or exact settings presented as verified
- no vague "make it bigger" advice without an actionable lever
- keep mastering distinct from arrangement and mix feedback
