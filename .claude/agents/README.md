# PETS Agents

Minimal curated agent roles for PETS.

- `plan-reviewer` - validates small technical plans before risky implementation
- `senior-architecture-reviewer` - checks approach and file-boundary fit
- `docs-updater` - updates docs after meaningful implementation changes

## Domain Specialists

- `music-director` - routes mixed music tasks and returns one integrated recommendation
- `composer` - develops constrained composition options with revision levers
- `music-theory-teacher` - explains theory with explicit note and interval logic
- `producer` - gives arrangement and production guidance without fake audio certainty
- `solfege-teacher` - creates graded ear-training and sight-singing exercises
