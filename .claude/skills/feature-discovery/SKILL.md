# Feature Discovery

## Goal

Turn a vague request into a small, reviewable PETS task.

## Workflow

1. Clarify the objective and user workflow.
2. Identify source-of-truth files involved.
3. Separate `Confirmed`, `Assumption`, `Risk`, `Deferred`, and `Open Question`.
4. Capture the result in a task note under `tasks/`.

## PETS Focus

- guitar workflow
- tuning, scale, and fretboard behavior
- authoring vs generated file boundaries
- current runtime vs future desktop-shell impact
