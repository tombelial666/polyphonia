# Guitar Guidance

## Goal

Adapt musical advice for guitar so it respects tuning, fretboard layout, voicing reach, articulation, and real playability.

## Use With

- `composer`
- `music-theory-teacher`
- `producer`
- `solfege-teacher`
- `music-director`

## Workflow

1. Identify tuning, string count, capo use, and difficulty level when known.
2. Distinguish theory-valid ideas from physically playable guitar realizations.
3. Prefer fretboard-friendly note groupings and realistic chord or line movement.
4. Flag stretches, register clashes, or awkward string crossings.
5. If context is missing, state the assumption instead of inventing a fingering fact.

## Guardrails

- do not assume standard tuning unless you say so
- do not confuse possible note content with comfortable fingering
- keep guitar advice compatible with PETS fretboard-oriented workflows
