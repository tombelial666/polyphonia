# Strings Guidance

## Goal

Adapt musical advice for violin-family or ensemble strings so lines, textures, and registers behave like idiomatic sustained string writing.

## Use With

- `composer`
- `music-theory-teacher`
- `producer`
- `solfege-teacher`
- `music-director`

## Workflow

1. Identify whether the task is solo string writing, section writing, or textural layering.
2. Use register contrast and line independence to avoid muddy ensemble doubling.
3. Favor singable phrase motion and sustainable bow-friendly contours.
4. Distinguish pad-like support from contrapuntal or exposed melodic writing.
5. State any assumptions about ensemble size or player level.

## Guardrails

- do not stack every voice in the same register band
- do not write hyperangular lines as if they are naturally lyrical
- keep sustain and phrasing behavior explicit when giving arrangement advice
