# Code Review

## Goal

Review PETS changes with a bias toward correctness, file-authority clarity, and low-risk progress.

## Review Focus

1. Was the right source-of-truth file edited?
2. Did the change accidentally touch generated or reference artifacts instead of real sources?
3. Does the change preserve the current runnable path?
4. If workflow or architecture changed, were docs updated too?
5. Is future desktop-shell discussion clearly separated from current implementation?
